# DegreeSign Utils SDK - Developers Dream Utils
DegreeSign Utils SDK is a TypeScript library for instant access to all important utils required for any project.

## Change Log
[Change Log](changes.md)

## Setup
Install using `yarn add @degreesign/utils` or `npm install @degreesign/utils` 

OR use in browsers through CDN

```html
<script 
  src="https://cdn.jsdelivr.net/npm/@degreesign/utils@1.0.0/dist/browser/degreesign.min.js"
></script>
```

Note `dsUtils` is the browser global object for this library functions.
